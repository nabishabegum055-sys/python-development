# 🧮 Interactive Calculator & Unit Converter

A beginner-friendly Python CLI application developed as part of my **InternCircle Python Internship – Task 2**.

## 📌 Project Description

This project is a menu-driven command-line application that performs basic arithmetic calculations and unit conversions.

The application is designed to help beginners understand Python fundamentals such as functions, conditional statements, loops, user input, and error handling.

## ✨ Features

### 🔢 Basic Calculator
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero validation

### 📏 Unit Converter
- Kilometers to Miles
- Celsius to Fahrenheit

### 🛡️ Input Validation
- Handles invalid numerical inputs
- Validates calculator operators
- Prevents division by zero
- Uses while loops for repeated input

## 🛠️ Technologies Used

- Python 3
- Functions
- Conditional Statements
- While Loops
- Exception Handling
- User Input
